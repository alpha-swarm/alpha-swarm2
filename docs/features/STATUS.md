## Critical Blockers

1. **WASI web-ui UPDATE queries** — The feedback and approve endpoints return 200 OK but SurrealDB status doesn't change. Root cause: WASI HTTP outgoing handler may handle multi-statement SQL differently. SELECT queries work fine, UPDATEs don't.

2. **Tool-use loop context bloat** — The text protocol adds ~500 tokens of tool format instructions which overflows small model context windows. Needs qwen2.5-coder:32b (128K context) which is still downloading.
