# Changelog

## v0.1.0 - 2026-04-09

### Features
- WASI-native architecture with 8 components and 10 portable crates.
- Zero-disk E2E via GitHub API and virt-git blobstore.
- Multi-model support with qwen2.5-coder 7b/14b/32b.
- Distributed inference via NATS providers.
- In-memory content-addressed git with SHA256 trees.
